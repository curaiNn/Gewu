# 格物 Gewu

格物致知。把高中物理的经典题型提炼成「母题」，为每道母题做一个可调参数的 HTML 动画模型，配上核心考点、结论、推导、变式和换皮题，帮助学生在脑中建立物理模型，遇到同类题能快速识别并解决。

## 在线示例

入口：<http://8.133.160.230/>（全部母题按模块列出，点卡片进入）

几个代表性页面：
- [竖直面内圆周运动：轻绳模型与轻杆模型](http://8.133.160.230/MEC-CIR-01.html)
- [牛顿第二定律的多过程问题（斜面模型、先加速后减速、传送带模型）](http://8.133.160.230/MEC-NEW-01.html)
- [电磁感应中的单杆模型（阻尼式 / 发电式）](http://8.133.160.230/EM-IND-01.html)
- [气缸活塞类问题（气体实验定律）](http://8.133.160.230/THM-GAS-01.html)

每个页面都能调参数、选预设情形播放动画，读数与结论公式实时对照；支持手机和深色模式。
